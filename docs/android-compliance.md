# Соответствие Android-клиента ТЗ

Основание: ТЗ на Android-приложение Test-DPLS версии 1.0 и ТЗ на устройство версии 1.2.

| Требование | Реализация | Автоматическая проверка | Стендовая проверка |
|---|---|---|---|
| Android 8.0+ | `minSdk = 26`, API-зависимые BLE permissions и GATT compatibility | Gradle build, unit tests, lint, статический contract job | Установка на API 26/30/31/35 |
| Портретная ориентация | `screenOrientation="portrait"` | Android contract job | Поворот телефона |
| Светлая и тёмная тема | системная тема Material 3 | compile/lint | визуальная проверка обеих тем |
| Защита парольных данных | `FLAG_SECURE`, пароль не сохраняется, массивы очищаются | Android contract job, unit tests валидации | скриншот/recents на телефоне |
| Пароль | минимум 8, только A-Z/a-z/0-9 | `AndroidComplianceRulesTest` | первичная настройка и смена пароля |
| Блокировка после ошибок | countdown по `retryAfter`, ввод отключён | unit test парсинга, Android build | 5 неверных попыток, ожидание 300 с |
| Поиск устройств | фильтр Service UUID, старт/стоп, лимит 60 с, сортировка RSSI | build + статический contract job | два Test-DPLS и посторонние BLE |
| Идентификация | подтверждение фактической отправки, countdown 60 с, досрочная остановка | unit constants/build | светодиод и аппаратный предел 60 с |
| Подключение | тайм-аут 10 с, bonding до протокола | build + статический contract job | неподключаемое устройство, отмена pairing |
| Шесть режимов | фактический `STATE_REPORT`, подтверждение опасного действия | протокольные unit tests | все режимы на стенде с С2000-КДЛ |
| Безопасный возврат | предупреждение 5 мин / потеря сессии >10 с | UI build, firmware host tests | отключение Bluetooth и уход из зоны связи |
| RSSI | активный `readRemoteRssi` и графическое/числовое отображение | Android build | ухудшение сигнала в активной сессии |
| Журнал | до 200 записей, sequence/time/type/parameter | build, существующие protocol tests | полная выгрузка и разрыв связи |
| Экспорт | UTF-8 CSV/TXT, ID+дата+время, save/share через FileProvider | unit test имени/CSV, contract job | открыть файлы сторонним приложением |
| Настройки | имя, пароль, аппаратный reset notice, сведения об устройстве | build | операции с реальным устройством |
| О приложении | versionCode/versionName, протокол, OSS | build + contract job | визуальная проверка |
| CI | firmware tests, Android test/lint/debug/release/AAB, artifacts | GitHub Actions | — |

## Ограничение автоматической приёмки

GitHub-hosted workflow не подтверждает электрическое переключение силовой части, реакцию С2000-КДЛ, светодиод или устойчивость конкретного телефона. Эти пункты считаются закрытыми только после выполнения ПМИ на реальном устройстве. Actions проверяет исходный код, протокол, сборку, статические требования и форматы данных.
