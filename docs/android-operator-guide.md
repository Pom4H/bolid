# Руководство оператора Android-клиента Test-DPLS

## Поиск и подключение

1. Включите Bluetooth и разрешите приложению поиск BLE-устройств. На Android 13+ также разрешите уведомления для фонового соединения.
2. Нажмите «Начать поиск». В списке отображаются имя, ID и RSSI. Поиск можно остановить вручную; автоматически он прекращается через 60 секунд.
3. Для физического подтверждения нажмите «Показать на объекте». Светодиод выбранного Test-DPLS включит сцену идентификации. Режим можно остановить вручную и он завершается автоматически не позднее 60 секунд.
4. Нажмите «Это нужное устройство» или сразу «Подключиться» в списке.
5. Подтвердите системное BLE-сопряжение. Приложение не управляет устройством до создания защищённой связки.

## Первичная настройка и вход

Для нового устройства задайте имя и пароль. Пароль должен содержать не менее восьми символов и состоять только из латинских букв и цифр. Пароль не сохраняется приложением.

После пяти неверных попыток устройство блокирует вход примерно на 300 секунд. Приложение показывает оставшееся время и не отправляет новые попытки до окончания блокировки.

Снимки экрана и изображение приложения в списке последних приложений блокируются системным флагом безопасности.

## Испытания

Перед включением режима убедитесь, что персонал предупреждён и последствия для С2000-КДЛ понятны. Каждый опасный режим требует отдельного подтверждения.

Приложение показывает фактический режим только после ответа устройства. Любой тестовый режим ограничен пятью минутами. При потере аутентифицированной сессии более чем на 10 секунд устройство должно самостоятельно вернуться в «Норма».

## Журнал

Экран журнала показывает номер записи, время, тип, параметр и расшифровку. Журнал можно сохранить или передать в CSV/TXT. Имя файла содержит ID устройства, дату и время создания.

## Настройки

Можно изменить имя и пароль, посмотреть версии приложения, протокола, прошивки и аппаратную ревизию.

Сброс пароля через приложение невозможен. Аппаратный сброс выполняется только при физическом доступе к входу `FACTORY_RESET` устройства.

## Проблемы с разрешениями

Нажмите «Открыть настройки приложения», разрешите Bluetooth/геопозицию для Android 8–11 и Nearby devices для Android 12+. После возврата приложение повторно проверит разрешения. Кнопка «Bluetooth» открывает системные настройки адаптера.
